3 边界：❌ 不列席董事会 / ❌ 不影响本职 / ❌ 不参与股权激励
顾问 F（0%）：外部顾问 / 品牌主理人
顾问 G（0%）：外部顾问 / 技术顾问（部门级，非公司高管）
转为全职后：可按《5 创始人内部协议》程序参与公司股权激励
第 9 条

股权转让 + 异议股东回购

内部转让：5 创始人之间可相互转让（4 创始人以上同意）
对外转让：需 5/5 同意 + 创始人 A同意 | 30 日内未答复视为同意 | 优先购买权
异议股东回购（公司法第 89 条）：5 年不分配 / 合并分立 / 章程修改使股东利益受损 | 60 日内协商 | 90 日内诉讼

第 17 条

月工资规则（5 创始人 + 外部顾问）

5 创始人月工资 = 上一年度净利润 × 50% / 12 × 个人工商比例（创始人 A 40% / 其他 4 人各 15%）
外部顾问费 = 上一年度净利润 × 10%（数量不限，按规则分配）
30 万门槛：上一年度净利润 < 30 万 → 次年无月工资/顾问费
亏损年度：净利润 < 0 → 次年 7 人均无月工资/顾问费
第 1 年：7 人全部无月工资（投入期，靠项目绩效奖励）
不设保护期：5 创始人本职工资和五险一金由本职单位承担
第 18 条

项目绩效奖励池（40% 项目毛利）

📊 计算公式
基础贡献 = 任务数 × 难度系数 × 完成时间系数
个人最终贡献 = 基础贡献 × 角色系数
个人实得 = 40% 池子 × 个人最终贡献 ÷ 全员最终贡献之和
🎯 3 维度飞书量化（每个任务在飞书录入）
维度取值说明
任务数已完成数 × 1
未完成数 × 0		已完成 1 个 = 1；未完成不计入（防止挂任务）
难度系数0.5 / 1 / 2简单 0.5 / 中等 1 / 困难 2
完成时间系数0.5-2延期 0.5 / 准时 1 / 提前 2
🎖️ 角色系数（10% 加权）
角色系数说明
普通参与者×1.0无加成
项目总负责人×1.1+10%
1 个阶段负责人×1.1+10%
项目总 + 1 个阶段×1.2+20%
项目总 + 2 个阶段×1.3+30%
兼任可累加：项目总负责人同时担任 N 个阶段负责人 = 1.0 + 0.1 × (1+N)
🚫 拒绝挂名（核心机制）
所有任务统一飞书量化，不区分"协调"和"普通"。基础贡献 0 → 加权 0 → 拿 0 元。
例：项目总负责人本月未做任何飞书任务 → 基础贡献 0 → 角色系数无效 → 实得 0
💰 数字案例（项目毛利 10 万 → 池子 4 万）
人员任务基础贡献角色系数最终贡献实得
创始人 A10 个一般任务10项目总+1 阶段×1.2121.7 万
创始人 B8 个一般任务8普通×1.081.14 万
创始人 C5 个一般+2 个困难81 阶段负责人×1.18.81.22 万
创始人 D0 个任务0项目总（挂名）×1.100（拒绝挂名）
全员最终贡献之和 28.8 → 4 万池子按比例分配
📋 配套规则
池子下限：单项目毛利 < 2 万 → 池子 = 0
适用范围：仅商业项目（孵化项目不适用）
称谓区分：5 创始人/新员工=项目绩效（工资），外部顾问=项目顾问费（劳务报酬）
发放流程：回款后 3 个工作日 → 创始人审核 → 公示 2 天 → 随当月工资发放
争议处理：创始人最终裁决
